# Broken Dawn — walkthrough mockup

A standalone, tappable phone-portrait prototype of a new first-15-minutes walkthrough for Broken Dawn. It is **not** the live game.

- Play it on your phone: open `index.html` (this branch is meant to be served via rawcdn.githack.com).
- The gold **MOCKUP** badge at the top opens a jump menu so you can skip to a screen or restart.
- Nothing here should be merged to `main` or deployed to GitHub Pages. Jason’s rule: mockups come before builds; no merge or deploy without an explicit yes.

Art, names, and the gold-and-teal HUD are reused from Kaos811/broken-dawn. See the report that accompanies this preview for the step list, goals, and anything invented for the mockup (the Energy collect orb, the Alliance board, and a few shortened goal numbers).
